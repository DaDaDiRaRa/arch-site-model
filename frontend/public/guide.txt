대지모델 생성기 사용 설명서
==============================================================
주소나 지도 영역만으로 5m 지형·실측 층수 건물·정사영상이 들어간 3D 대지모델을
만들어 SketchUp·Rhino로 가져옵니다.

웹사이트 : https://arch-site-model-30350777436.asia-northeast3.run.app
설명서   : 위 주소 + /guide.html (그림 포함 버전)
최종 수정: 2026-09-21

--------------------------------------------------------------

2. 웹사이트로 만들기

1. 어떤 방법을 쓸까
--------------------------------------------------------------
두 가지 방법이 있고, 결과물의 내용은 같습니다.

[웹] 웹사이트에서 받기
  - 설치할 것이 없습니다. 브라우저에서 영역을 고르고 파일을 받아 SketchUp이나
    Rhino에서 엽니다.
  - 처음 쓰거나, Rhino를 쓰거나, 파일을 동료에게 넘길 때.

[SketchUp] 확장으로 바로 만들기
  - SketchUp 메뉴에서 주소를 넣으면 지금 열린 모델 안에 바로 조립됩니다.
    한 번 설치가 필요합니다.
  - SketchUp으로 작업을 자주 할 때.


2. 웹사이트로 만들기
--------------------------------------------------------------
(1) 대지 위치 정하기
    주소를 입력하고 [지도에서 찾기](또는 Enter)를 누르면 지도가 이동하고
    반경만큼의 정사각형이 놓입니다.
    - 지도를 클릭하면 그 지점을 중심으로 정사각형이 다시 놓입니다.
    - [사각형으로 그리기]를 누른 뒤 지도에서 드래그하면 원하는 모양의 사각형을
      고를 수 있습니다.
    - 영역 한 변은 20m~4km입니다. 범위를 벗어나면 사각형이 빨갛게 바뀌고
      생성 버튼이 막힙니다.
    - 오른쪽 위 레이어 버튼으로 위성 지도로 바꿀 수 있습니다.

(2) 층고
    건물 높이 = 실측 층수 x 층고. 기본 3.5m(사내 표준)이고, 바꾸면 이 브라우저가
    기억합니다.

(3) 포함할 레이어
    지형(TIN)        5m 지형. 평지는 큰 삼각형, 경사지는 촘촘하게(오차 25cm 이내).
    정사영상 텍스처  항공사진을 지형에 입힙니다. 넓은 영역은 해상도가 자동으로
                     한 단계 낮아집니다.
    지적(대지경계)   필지 경계선을 지형 위에 얹습니다.
    도로(노면)       도로·보도 면과 차선. 지형을 도로에 맞게 깎거나 돋워 이음매
                     없이 붙입니다.
    수계(하천·호소)  하천·호수를 평평한 수면으로 넣습니다.
    도시계획         지구단위계획구역, 도시계획도로, 공원·녹지·광장 등 결정선.
                     표시만 하며 법적 판단이 아닙니다.
    자동 QA          급경사에 놓인 건물, 겹친 건물, 지형 밖 건물 등을 찾아 목록과
                     3D 핀으로 보여 줍니다.
    용도지역         대지의 용도지역을 조회해 표시합니다(주소 입력 시).

(4) [모델 생성]
    보통 20초~2분 걸립니다(영역이 넓고 도로를 켜면 더 걸림).

(5) 결과 확인 후 받기
    3D 미리보기(회전·확대), 데이터 신뢰도 리포트(실측/추정 층수 비율, 지형 출처),
    경고를 확인한 뒤 받습니다.
    - [SketchUp용 받기 (.dae, zip)] : .dae, .3dm, 정사영상, 좌표 안내문이 모두
      들어 있습니다.
    - [Rhino용 받기 (.3dm)]         : .3dm만 받습니다(텍스처를 쓰려면 zip을 받으세요).

  ※ 주황색 건물은 층수 정보가 없어 1층으로 "추정"한 건물입니다.
    실측 건물과 구분해서 보세요.


3. SketchUp에서 열기 (.dae)
--------------------------------------------------------------
(1) 받은 zip의 압축을 먼저 풉니다. 텍스처(정사영상 PNG)가 같은 폴더에 있어야 합니다.
(2) SketchUp에서 파일(File) > 가져오기(Import)
    → 파일 형식 COLLADA (*.dae) → 풀어 둔 .dae 선택.
(3) 모델이 마우스를 따라오면 원점 근처를 클릭해 놓습니다.

들어오는 구조
  - 지형(정사영상 텍스처, 흙색 단면), 건물(한 동씩 컴포넌트, 이름 예: 12층_OO아파트),
    도로·보도·차선, 지적, 도시계획이 각각 묶여 있습니다.
  - 실제 크기(미터)로 들어옵니다. 층수 추정 건물은 이름 끝에 [층수추정]이 붙고
    주황색입니다.

  ※ 지형에 삼각형 선이 많이 보이면
    SketchUp은 .dae를 가져올 때 모서리를 부드럽게 처리하지 않습니다.
    지형 그룹을 더블클릭해 열고 Ctrl+A → 우클릭 "모서리 부드럽게/매끄럽게".
    아래 5번의 SketchUp 확장이 설치돼 있으면 가져오는 순간 자동으로 처리됩니다.


4. Rhino에서 열기 (.3dm)
--------------------------------------------------------------
.3dm을 그대로 엽니다(zip에서 받았다면 PNG와 같은 폴더에 두면 텍스처가 붙습니다).
단위는 미터입니다.

레이어
  buildings / buildings_unverified
      실측 층수 건물 / 층수 추정 건물. 객체 속성에 층수·건물명이 들어 있습니다.
  terrain
      지형 메시(정사영상 텍스처)
  terrain_surface (기본 꺼짐)
      NURBS 지형 서피스. 5m 격자점을 정확히 지나는 3차 곡면이라 Split·Trim·
      곡선 투영·솔리드 작업에 씁니다. 메시와 같은 자리라 쓸 때 terrain을 끄고
      켜세요.
  roads · sidewalks · lanes · water
      도로 면, 보도 면, 차선, 수면
  cadastral
      지적선(지형 높이에 얹음). 객체 이름은 PNU.
  도시계획_...
      분류별 결정선. 객체 이름은 결정 도면명(예: 소로3류).
  walls · qa_warn · qa_info
      옹벽 상단선(높이 속성) · QA 결함 핀

  ※ 정밀한 도로 경계는 메시가 더 정확합니다(서피스는 5m 곡면이라 도로 절토 턱을
    부드럽게 넘깁니다).


5. SketchUp 확장으로 바로 만들기
--------------------------------------------------------------
설치 (한 번만)
  (1) 확장 받기: 웹사이트 주소 + /api/extension.rbz
      (설명서 페이지의 [확장 받기] 버튼. 항상 서버와 같은 최신 버전입니다.)
  (2) SketchUp 확장 프로그램(Extensions) > 확장 관리자(Extension Manager)
      → 확장 설치(Install Extension) → 받은 .rbz 선택 → 경고창에서 [예].
  (3) SketchUp을 다시 켭니다. 예전 버전이 있으면 같은 방법으로 덮어 설치하면 됩니다.

사용
  (1) 확장 프로그램 > 대지모델 생성... 을 누르면 입력 창이 뜹니다.
  (2) 주소, 반경, 층고(마지막 값 기억), 지형·정사영상·도로·수계·QA·도시계획을
      고르고 [모델 생성].
  (3) 10~60초 뒤 지금 열린 모델에 arch-site-model 그룹으로 조립되고, 창에
      "완료 — 건물 N동"이 표시됩니다.
      건물은 파랑(실측)·주황(추정), 빨간 막대는 자동 QA가 찾은 결함 위치입니다.

함께 되는 것
  - 웹에서 받은 .dae를 가져오면 지형·도로 모서리가 자동으로 정리됩니다
    (건물은 각진 그대로).
  - 태그(레이어)로 terrain, buildings, roads, 도시계획_... 등을 따로 켜고 끌 수
    있습니다.

  ※ "Ruby"는 SketchUp 확장이 쓰는 언어일 뿐, 직접 코드를 실행할 일은 없습니다.
    메뉴에서 창을 열어 쓰면 됩니다.


6. 좌표·단위
--------------------------------------------------------------
  - 1 단위 = 1m. 모델 원점(0,0,0)은 영역 남서쪽 근처의 한 점이고,
    높이(Z)는 해발 표고 그대로입니다.
  - 원점의 실제 좌표(EPSG:5186 중부원점, WGS84 위경도)는 zip 안의
    readme_coords.txt와 .3dm 문서 속성(origin_offset_x/y)에 있습니다.
  - 수치지도·GIS 도면과 맞추려면 전체를 (0,0) → 안내문의 X, Y로 이동하세요.


7. 데이터 출처와 한계
--------------------------------------------------------------
  지형
    출처: 국토지리정보원 수치지형도(1:5,000) 등고선·표고점으로 만든 5m 격자
    전국 17개 시도. 전라남도는 표고점·도로·수계가 빠져 있어 봉우리가 평평할 수
    있습니다(보완 예정). 나무·건물 높이가 섞이지 않은 맨땅 높이입니다.
  건물
    출처: VWorld 건물(층수)
    높이 = 층수 x 층고(가정). 실측 높이가 아닙니다. 층수 없는 건물은 1층 추정(주황).
  정사영상
    출처: VWorld 위성영상. 약 0.5m/화소, 넓은 영역은 약 1.2m/화소.
  지적·도시계획
    출처: VWorld 연속지적·도시계획정보(UPIS).
    도시계획은 결정선 표시만, 법적 판단은 법규 앱에서.
  도로·수계·옹벽
    출처: 수치지형도 도로·수계·옹벽 레이어.
    고가도로·교량 상판은 표현하지 않습니다(지면 기준).


8. 문제 해결
--------------------------------------------------------------
  SketchUp에서 텍스처가 안 보임
    → zip을 푼 다음 .dae를 가져오세요. zip 안에서 바로 열면 PNG를 못 찾습니다.
  지형이 안 나오고 건물만 나옴
    → 결과 화면 경고를 확인하세요. 5m 지형이 없는 곳이면 건물만 만들어집니다.
  화면이 예전 모습
    → 새 버전 배포 뒤 브라우저 캐시 때문입니다. Ctrl+F5.
  오래 걸림
    → 영역을 줄이거나 도로를 끄면 빨라집니다. 최대 약 2분.
  확장 메뉴가 없음
    → 확장 관리자에서 arch-site-model이 켜져 있는지 확인하고 SketchUp을 다시 켜세요.
  확장 조립 중 오류
    → 확장 프로그램 > 개발자 > Ruby 콘솔에 원인이 찍힙니다.
      그 내용을 담당자에게 보내 주세요.
